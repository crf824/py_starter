# py_starter · Python 零基础陪练项目

从零开始学 Python 的陪练练习项目，共 7 课，每课一个可运行文件。

| 文件 | 内容 |
|------|------|
| `lesson1.py` | 第一行代码 `print` |
| `lesson2.py` | 变量 & 数据类型 |
| `lesson3.py` | 条件判断 `if / elif / else` |
| `lesson4.py` | 循环 `for / while` |
| `lesson5.py` | 函数 `def` |
| `lesson6.py` | 文件读写（`.txt` / `.csv`） |
| `lesson7.py` | 综合小项目：短线复盘小工具 |

## 运行方式
在本机终端（用 `py`，不是 `python`）：
```bash
cd py_starter
py lesson7.py
```
运行 `lesson7.py` 会把一周盈亏追加写入 `report.txt`，形成一个可长期积累的复盘台账。

> 修改 `lesson7.py` 顶部的 `week_pnl` 列表，换成自己的数据即可。
